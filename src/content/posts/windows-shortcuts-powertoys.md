熟练用键盘的人，效率往往是只会点鼠标的人的好几倍。整理一批我每天都在用的 Windows 快捷键，再加上微软官方的免费神器 PowerToys，能让你的鼠标少跑一半路。

## 每天都该用的快捷键

| 快捷键 | 作用 |
| :-- | :-- |
| `Win + E` | 打开文件资源管理器 |
| `Win + D` | 一键显示 / 隐藏桌面 |
| `Win + L` | 立刻锁屏（离开工位必备） |
| `Win + V` | 剪贴板历史（可存多条） |
| `Win + Shift + S` | 截图（可框选区域） |
| `Win + .` | 打开 emoji 与符号面板 |
| `Win + 方向键` | 窗口贴边分屏 |
| `Win + Tab` | 任务视图与虚拟桌面 |
| `Win + 数字` | 打开任务栏对应位置的程序 |
| `Alt + Tab` | 在窗口间快速切换 |
| `Ctrl + Shift + Esc` | 直接打开任务管理器 |

:::tip[最被低估的一个]
`Win + V` 的剪贴板历史，很多人不知道。开启后，你复制过的多条内容都能随时翻出来再贴——用过就回不去了。
:::

## PowerToys：微软官方的效率神器

[PowerToys](https://github.com/microsoft/PowerToys) 是微软开源的一套系统增强工具，免费而强大。挑几个最实用的模块：

- **FancyZones**：自定义窗口布局。把屏幕划成你想要的网格，拖窗口时自动吸附，多显示器党的福音。
- **Run（`Alt + Space`）**：快到飞起的启动器。敲几个字母就能启动程序、算算术、找文件，类似 Mac 的 Spotlight。
- **PowerRename**：批量重命名，支持正则，几百个文件一键改名。
- **Color Picker（`Win + Shift + C`）**：屏幕取色器，随时拾取任意像素的颜色值。
- **Text Extractor（`Win + Shift + T`）**：屏幕 OCR，把图片、视频里的文字直接框选、复制出来。
- **Always on Top（`Win + Ctrl + T`）**：让任意窗口置顶，边看教程边操作很方便。
- **Keyboard Manager**：重映射按键或快捷键，把不顺手的键位改成你喜欢的样子。

:::note[怎么装]
在微软商店搜索「PowerToys」即可一键安装，或到它的 GitHub 仓库下载。装好后，每个模块都能单独开关、自定义快捷键。
:::

熟悉这些之后你会发现，很多原本要点好几下鼠标的操作，一个组合键就搞定了。效率的提升，往往就藏在这些不起眼的细节里。
