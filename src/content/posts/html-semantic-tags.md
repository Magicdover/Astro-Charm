很多人写 HTML，从头到尾只用 `<div>` 和 `<span>`。但 HTML5 其实提供了一整套**语义化标签**——它们不只是「换了个名字的 div」，而是在告诉浏览器、搜索引擎和读屏软件：这块内容「是什么」。

## 页面骨架

一个语义化的页面，结构清晰得像一份大纲：

```html
<body>
  <header>网站页眉：logo、标题</header>
  <nav>主导航链接</nav>
  <main>
    <article>
      <h1>一篇文章的标题</h1>
      <section>
        <h2>章节一</h2>
        <p>正文……</p>
      </section>
      <aside>侧边补充：相关链接、注释</aside>
    </article>
  </main>
  <footer>网站页脚：版权、备案</footer>
</body>
```

:::note[它们的分工]
- `header` / `footer`：页眉与页脚，可用于整页，也可用于单篇文章。
- `nav`：导航链接的集合。
- `main`：页面的主体内容，一个页面只应有一个。
- `article`：可独立成篇的内容（一篇博文、一条评论）。
- `section`：主题相关的一个区块，通常带标题。
- `aside`：与主内容相关、却可以抽离的旁支（侧边栏）。
:::

## 几个好用的小标签

除了骨架，还有一批表意精确的小标签：

| 标签 | 用途 |
| :-- | :-- |
| `<time>` | 标记日期或时间，可带机器可读的 `datetime` |
| `<figure>` / `<figcaption>` | 图片及其配套说明 |
| `<mark>` | 高亮标记一段文本 |
| `<details>` / `<summary>` | 可折叠的展开面板（无需 JS） |
| `<progress>` | 进度条 |
| `<abbr>` | 缩写，可带完整解释 |

比如一个纯 HTML、无需 JavaScript 的折叠面板：

```html
<details>
  <summary>点我展开</summary>
  <p>这段内容默认隐藏，点击标题才会显示。</p>
</details>
```

## 为什么值得

:::tip[语义化的三重回报]
1. **可读**：结构一目了然，别人（和半年后的你）更容易看懂。
2. **SEO**：搜索引擎更好地理解页面主次，利于收录与排名。
3. **无障碍**：读屏软件能据此为视障用户正确地朗读与导航。
:::

写 HTML 时多花一秒选对标签，是一件回报率极高的小事。毕竟，代码不只是写给机器运行的，更是写给人读的。
