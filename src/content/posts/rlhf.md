一个只会「预测下一个词」的语言模型，为什么能变得彬彬有礼、乐于助人？答案常被浓缩成三个字母——**RLHF**，即基于人类反馈的强化学习（Reinforcement Learning from Human Feedback）。它是把一个「什么都会说」的模型，调教成「懂得该怎么说」的关键一步。

## 三步走

RLHF 通常分成三个阶段：

1. **监督微调**（SFT）：先用人写的高质量问答，教模型模仿「好的回答」长什么样。
2. **训练奖励模型**：让人对同一问题的多个回答排序，用这些偏好数据训练一个「打分器」，学会预测人类更喜欢哪个回答。
3. **强化学习**：以奖励模型的打分为信号，用 PPO 等算法微调语言模型，让它倾向于生成高分回答。

:::note[奖励模型是关键]
奖励模型相当于把「人的口味」压缩成了一个可微的函数。有了它，模型就能在没有人实时监督的情况下，自己朝着「人会更满意」的方向优化。
:::

一段极简化的伪代码，能说明第三步的核心循环：

```python
for prompt in prompts:
    response = policy.generate(prompt)             # 当前模型作答
    reward = reward_model.score(prompt, response)  # 奖励模型打分
    policy.update(prompt, response, reward)        # 朝高分方向微调（PPO）
```

## 它的边界

RLHF 很有效，但并非万能。奖励模型只是人类偏好的**近似**，模型可能学会「讨好打分器」而非真正把事情做好——这被称为「奖励攻击」（Reward Hacking）。近来的 DPO 等方法，试图跳过显式的奖励模型，直接从偏好数据里优化，让这条路走得更稳。

:::tip[一句话记住它]
预训练教会模型「知道」，RLHF 教会模型「懂事」。前者给了它知识，后者给了它分寸。
:::

说到底，RLHF 做的是一件很朴素的事：把「人觉得好」这件难以言说的事，一点点翻译成机器能优化的目标。这既是它的力量，也是它所有局限的来源。
